## 使用方式

VOFA 连接板子的 USB 虚拟串口，协议选择 **JustFloat**；指令以普通 ASCII 文本发送，每条带换行 `\n`（CRLF 也可以），不要用十六进制发送。

上电保留原程序的自动对齐、编码器标定流程，完成后自动进入脉冲接收和波形输出。等待标定完成后再发送运动指令。内部模拟不需要另一块板、不需要外接跳线，也不依赖 PC9 的物理使能电平。

## 常用指令

| 指令 | 用途 |
|---|---|
| `current id 300` | d 轴电流目标 300 mA，自动输出电流波形 |
| `current iq 200` | q 轴电流目标 200 mA，自动输出电流波形；会产生转矩，不是速度控制 |
| `speed 200` | 速度环目标 200 rpm，自动输出速度波形；负数反转 |
| `sim start 9600 1000 1` | 按外部板参考 S 曲线产生 9600 个脉冲，速度参数 1000 rpm，正向 |
| `sim hz 800 1000 1` | 恒定 1000 Hz 产生 800 个脉冲，正向；最后一颗后直接停止发脉冲 |
| `sim stop` | 立即停止后续模拟脉冲，保留接收端闭环定位和波形 |
| `sim status` | 关闭波形并输出模拟器文本状态，不停止发脉冲或电机控制 |
| `pulse vofa on` | 恢复脉冲模式波形，不切换模拟/真实来源 |
| `pulse on` | 停止模拟，切回 PC7/PC8/PC9 真实 STEP/DIR/EN 输入，并输出波形 |
| `wave off` | 只关闭波形，控制继续运行 |
| `stop` | 停止模拟和电机控制输出，同时关闭波形；不保持位置 |
| `help` | 关闭波形并显示上述简明帮助；不停止控制 |

`current`、`speed`、`sim` 指令自动切换对应测试模式；同一速度模式再次发 `speed`，或同一电流轴再次发 `current`，直接更新目标。模拟运行中再次发启动指令会拒绝，先 `sim stop` 再启动。波形期间拒绝的无效指令不插入 ASCII 错误文字，以免破坏 JustFloat；排查命令可先 `wave off`。

电流目标范围为 -1000～1000 mA；首次启动要求非零，同轴运行后允许设为 0。速度范围 -3000～3000 rpm。`sim start` 的速度参数范围 45～3000 rpm，`sim hz` 的频率范围 600～40000 Hz；脉冲数 1～10000000，方向只能是 `1` 或 `-1`。这些是接口允许范围，不表示电机在所有负载下都能跟随。

旧调试指令保留兼容，但 `help` 只显示常用指令。需要文本查询接收端时，先 `wave off`，再发原有 `pulse status` 或 `speed status`。

## 验证“脉冲什么时候停，接收端事先不知道”

低速恒频、随时中断示例（两条指令分开发送）：

```text
sim hz 1000000 1000 1
```

运行中在任意时刻发送：

```text
sim stop
```

这时只停止生成新的 STEP。接收端不会收到“结束”“剩余数量”“最终目标”等信息，仍按实际已经收到的脉冲数自行判停、定位。观察 I1 是否停止增加、I4 是否收敛到 I2，以及 I13 是否最终变为 1。

有限数量、自然结束示例：

```text
sim start 800 200 1
```

当前每脉冲对应 5 个编码器计数，4000 个计数一圈，因此 800 个脉冲对应 1 圈，9600 个对应 12 圈。多次模拟之间累计目标位置继续保留；`stop` 后重新启动脉冲模式，会以当时实际编码器位置重新建立起点。

**验证脉冲结束后的定位请用 `sim stop`，不要用 `stop`。** 后者撤销闭环输出，不能用于验证保持定位。

## JustFloat 通道（从 I0 开始）

每个通道为 4 字节小端 float，帧尾固定 `00 00 80 7F`。各模式自动选择各自帧，切换模式后按对应通道重新选择曲线。正常目标发送频率约 1 kHz，USB 忙时可能缺帧。

### 电流环：9 通道，40 字节/帧

| 通道 | 内容 | 单位 |
|---|---|---|
| I0 / I1 | Id 目标 / 实际 | mA |
| I2 / I3 | Iq 目标 / 实际 | mA |
| I4 / I5 | d / q 轴输出电压 | mV |
| I6 | 电压饱和标志 | 0/1 |
| I7 | 测试故障码 | 0 正常 |
| I8 | 电流遥测丢样数 | 次 |

### 速度环：5 通道，24 字节/帧

| 通道 | 内容 | 单位 |
|---|---|---|
| I0 / I1 | A / B 相实际电流 | A |
| I2 | 实际 Iq | A |
| I3 / I4 | 目标 / 实际速度 | rpm |

### 脉冲接收、模拟：18 通道，76 字节/帧

| 通道 | 内容 | 单位 |
|---|---|---|
| I0 | 系统时间 | ms |
| I1 | 接收端累计接受脉冲数 | pulse |
| I2 | 累计脉冲目标 PulsePos | encoder count |
| I3 | 内部轨迹目标 CmdPos | encoder count |
| I4 | 实际编码器位置 | encoder count |
| I5 / I6 | 速度环目标 / 实际速度 | rpm |
| I7 / I8 | Iq 目标 / 实际 | A |
| I9 | 模拟器本轮已发送数 | pulse |
| I10 | 模拟器是否仍发脉冲 | 0/1 |
| I11 | 最近 STEP 后首次进入 ±1 count 的耗时 | ms |
| I12 | 最近 STEP 后确认稳定到位的耗时 | ms |
| I13 | 稳定到位标志 | 0/1 |
| I14 | 脉冲遥测缺失计数 | 次 |
| I15 | 模拟器比较调度迟到计数 | 次 |
| I16 / I17 | 最近 STEP 时锁存的脉冲目标 / 实际位置 | encoder count |

稳定到位沿用原代码标准：无后续脉冲、位置误差在 ±1 count 内、速度绝对值 ≤6 rpm，持续 20 ms。I12 包含这 20 ms 确认时间，必须结合 I13 看；I11 仅表示首次经过目标，数值为 0 本身不证明到位。新的 STEP 会重置末端测量候选。

I1 是接收端本次使能后的累计值，I9 是模拟器本轮值，连续多轮不能直接比较绝对值，应比较 I1 的本轮增量。I16−I17 表示最近 STEP 到来时的实际跟随误差；发完后继续保留最后一颗的快照。float 对绝对值大于 16777216 的整数不能逐计数精确显示，长行程最终精度不要只依据波形整数显示判断。

## 模拟实现与边界

- TIM3 CH3 比较中断逐颗产生软件 STEP，真实 PC7 仍使用 TIM3 CH2 捕获；两者进入同一个接收计数核心。模拟来源选定后保持有效，发完不会撤销模拟使能来暗示结束。模拟期间忽略物理 STEP，避免混入另一来源；`pulse on` 切回真实输入。
- 曲线参考外部板 `App/MotorCtrl/motorctrl.c`、`s_func_factor.h` 和 `App/sysConfig/sysconfig.h`：当前第 2 号 1000 点表、步长 5、600 Hz 下限参数，长行程前后各 200 个脉冲为斜坡。短行程缩短斜坡，不会突然跳到长行程最高频率。
- 曲线速度参数按本机 800 pulse/rev 换算成外部表的 aimFreq；表值从 0.1192 到 0.8787，所以 `sim start ... 1000 ...` 的实际巡航速度并不是恰好 1000 rpm。恒频 `sim hz` 则直接指定脉冲频率，1000 Hz 对应 75 rpm。
- 参考曲线模式包含外部 ARR 整数截断及 ARR+1 定时周期。本模拟没有复制外部板的传感器状态机、毫米/转速换算、PWM 启动及寄存器更新相位，不应视为外部整机逐边沿完全一致的仿真。
- 接收时间戳现使用 TIM3 CCR3 对应的比较事件时刻，模拟真实捕获寄存器锁存边沿的语义；ISR 延迟由 `sim status` 的 `irq_max_ticks` 单独记录（除以 10.5 为 μs）。实际处理仍有中断延迟；I15 反映调度过期次数。模拟不经过输入光耦、GPIO 电气采样和线路，不能替代真实外部 STEP 的电气验证。
- 接收端原有判停、轨迹和控制环参数保持本次修改前版本。增加模拟功能不代表已经解决或验证了实际抖动、末端过冲和定位误差。
